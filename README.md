# Mesa Lista

Aplicación web para gestionar reservas de Casa Oliva, desarrollada por Marcelo Masias con React y Vite.

## Contenido del repositorio

- `mesa-lista/`: código fuente de la aplicación.
- `mesa-lista/README.md`: instalación, ejecución y funcionalidades.
- `.gitignore`: exclusión de dependencias, compilados y archivos de configuración local.

## Prototipo de interfaz

[Abrir el prototipo interactivo en Figma](https://www.figma.com/design/1etvbSIIouey6BuMXAo5t3/Mesa-Lista---Sistema-de-reservas?node-id=3-2&t=wXtp6U56Uw6XDTLV-1)

## Ejecutar el proyecto

```bash
cd mesa-lista
npm install
npm run dev
```

La aplicación es un prototipo frontend que guarda datos de demostración en el navegador. No incluye servidor, autenticación ni sincronización entre dispositivos.
